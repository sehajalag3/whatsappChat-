📊 WhatsApp Chat Analysis 📌 Project Overview

This project performs an exploratory analysis of WhatsApp chat data using Python. The goal is to extract useful insights such as message activity, most active users, word usage, and emoji trends from an exported WhatsApp chat file.

The project is implemented as a Google Colab notebook and is based on the concepts discussed in the CampusX WhatsApp Chat Analysis video.

🎯 Objectives

Parse raw WhatsApp chat .txt files

Clean and structure chat data

Analyze user activity and message frequency

Generate visual insights using plots and word clouds

Perform emoji usage analysis

🧰 Technologies Used

Python 3

Pandas – data manipulation

Matplotlib – data visualization

WordCloud – text visualization

Emoji – emoji extraction

Google Colab – execution environment

📂 Dataset

Source: Exported WhatsApp chat

Format: .txt

Note: Chat exported without media

Privacy: Personal data is not included in this repository

🧠 Features Implemented

Universal WhatsApp chat parser (supports Android & iOS formats)

Multiline message handling

Total message and user count

Top 10 most active users visualization

Word cloud generation

Emoji frequency analysis

▶️ How to Run the Project

Open the notebook in Google Colab

Run all cells

Upload a WhatsApp chat .txt file when prompted

View the generated analysis and visualizations

📊 Output

Message statistics

Bar chart of top active users

Word cloud of frequently used words

Emoji usage bar chart
